# LSystem_Generative_Art

An L-System-Based generative art system created for IAT 460.

## How to Run

1. Open 'L_System_based_artwork_generator.ipynb' in Google Colab.
2. Run the code cells from top to bottom.
3. The notebook will generate L-ssytem visual patterns/art using turtle graphics.
4. To vary outputs, adjust the following parameters: iterations, turning angle, and movement distance.

## Requirements

- Google Colab
- Python
- ColabTurtle
